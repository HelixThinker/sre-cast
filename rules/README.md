# AI Rules

This directory contains short, portable rules for AI-assisted CAST analysis.
They should be usable independently of a specific AI product whenever possible.

## Planned rules

- Evidence and provenance
- Facts, hypotheses, and unknowns
- Blameless explanatory language
- CAST terminology
- Source and page citations
- Recommendation traceability
- Human review boundaries

Rules should define quality constraints, not prescribe a complete workflow. Full
workflows belong in [`skills/`](../skills/README.md).

CAST analysis should explain what happened and why, without assigning blame or
stopping at a claimed root cause. See the
[CAST Handbook, pp. 7-8](https://psas.scripts.mit.edu/home/get_file4.php?name=CAST_Handbook.pdf#page=7)
and the comparison
of accusatory and explanatory analysis on
[pp. 19-23](https://psas.scripts.mit.edu/home/get_file4.php?name=CAST_Handbook.pdf#page=19).
