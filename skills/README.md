# Review skill

[`sre-cast-review`](sre-cast-review/SKILL.md) helps an engineer review an SRE
postmortem using CAST: examine evidence and control relationships, prioritize
questions, and connect improvements to the findings.

Start with the [installation and usage guide](sre-cast-review/README.md).
The package includes the workflow, focused method notes, an adaptable output
template, and Codex display metadata. It can work with incomplete evidence and
continue a review after new answers arrive.

The [worked reviews](../examples/README.md) show the approach in use. The earlier
`mock-cast-foundation` prototype in
[PR #8](https://github.com/HelixThinker/sre-cast/pull/8) is historical starting
material; use `sre-cast-review` for the current workflow.
