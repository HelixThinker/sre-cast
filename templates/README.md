# Templates

This directory contains reusable, tool-independent templates shared by AI skills
and worked examples.

Likely templates include:

- Incident and evidence index
- System boundary, losses, hazards, and constraints
- Neutral event description and open questions
- Safety control structure
- Controller analysis
- Systemic factors
- Recommendations and effectiveness follow-up
- Final CAST report

Templates provide a consistent starting point while preserving the iterative
nature of CAST. The foundational information and five analysis parts are
described in the
[CAST Handbook, pp. 34-45](https://psas.scripts.mit.edu/home/get_file4.php?name=CAST_Handbook.pdf#page=34).
